# ECS 191 App Clone Proposal

## 1. The App

I plan to clone the workout logging app Strong. 

## 2. The Fundamental Problem

The main problem this app solves is making a simple workout app that allows users to track workouts and times between sets without having a lot of clutter.

## 3. What I'll Keep

I plan to keep basic functionality like workout logging, tracking the total workout time, time between sets, track their weights and their reps. 

## 4. What I'll Change or Remove

I plan to remove alot of the clutter most of these apps have. I want this app tailored to people who are familiar with the gym and have their own workouts planned out. The app will allow users to create their workout with what ever exercises they want. 

When users begin a workout they created, it will start a total workout timer. When users start a specific excerise the app will start a timer between sets.

Users will be able to enter their Age, Weight and Height to get an estimated caloric burn after their workouts depending on the excersise and the working reps or set they use.

The Core Loop will be:

Create a workout -> Select a workout in saved workouts -> Log Excerise / Set / Reps / Weights -> rest timer -> total workout timer -> End Workout -> Total Caloric burn
